#    - Tracks timing and success/failure of each step

# ALGORITHM DETAILS
# =================
#
# STAGE 1: Red Mask Detection
#   - Detects red regions using color space constraints
#   - Algorithm:
#     * Condition 1: r > g + margin  (red dominant over green)
#     * Condition 2: r > b + margin  (red dominant over blue)
#     * Condition 3: g < b + margin  (orange rejection)
#     * Condition 4: r > MIN_RED     (minimum brightness)
#   - Dynamic margin = r >> 3 (divide by 8)
#   - Output: Binary mask (1 = red pixel, 0 = non-red)
#
# STAGE 2: Morphology Filter
#   - Cleans up red mask using morphological operations
#   - Algorithm:
#     * Dilation: Expand regions with 3x3 kernel
#     * Erosion: Shrink regions with 3x3 kernel
#     * Combined: Closing operation (remove small holes)
#   - Output: Refined binary mask
#
# STAGE 3: Connected Component Labeling (CCL)
#   - Identifies individual regions/objects in mask
#   - Algorithm: 8-connectivity flood fill
#   - Output: Label map (each region gets unique integer label)
#
# STAGE 4: Geometry Filtering
#   - Extracts bounding boxes for each region
#   - Computes: xmin, xmax, ymin, ymax, width, height, area
#   - Filters: Removes invalid regions (too small/large)
#   - Output: Bounding box coordinates for each detection


# COMPARISON METRICS
# ==================
#
# ACCURACY: (TP + TN) / Total
#   - Percentage of correctly classified pixels
#   - 100% = Perfect match
#
# PRECISION: TP / (TP + FP)
#   - How many detected pixels are correct
#   - High precision = few false positives
#
# RECALL: TP / (TP + FN)
#   - How many actual pixels are detected
#   - High recall = few false negatives
#
# F1-SCORE: 2 * (Precision * Recall) / (Precision + Recall)
#   - Harmonic mean of precision and recall
#   - Values 0-1, higher is better
#
# Confusion Matrix:
#   - TP (True Positive):   golden=1, rtl=1 ✓
#   - TN (True Negative):   golden=0, rtl=0 ✓
#   - FP (False Positive):  golden=0, rtl=1 ✗
#   - FN (False Negative):  golden=1, rtl=0 ✗


# TROUBLESHOOTING
# ===============
#
# Issue: "FileNotFoundError: Could not open RTL output files"
#   Solution: Run RTL simulation first to generate actual_mask_out.txt
#             and actual_morph_out.txt in the data directory
#
# Issue: "Accuracy is not 100%"
#   Possible Causes:
#   - RTL synthesized with different rounding behavior
#   - Timing issues in RTL causing off-by-one errors
#   - Different image scaling in RTL
#   Solution: Check detailed_report.txt for error region breakdown
#
# Issue: "Plots show "No differences"
#   This is GOOD! RTL matches golden model perfectly
#   Solution: Verify timing is correct, no data corruption
#
# Issue: "Memory error loading large image"
#   Solution: Reduce image resolution or increase system RAM
