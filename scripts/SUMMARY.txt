================================================================================
                          KEY FEATURES & METRICS
================================================================================

PROCESSING STAGES:
──────────────────
1. Red Mask Detection
   - Color space filtering (R > G+margin, R > B+margin, etc.)
   - Pixel count: depends on image content
   - Output: Binary mask (1 bit per pixel)

2. Morphology Filter
   - Dilation: expand regions (3×3, 1 iteration)
   - Erosion: shrink regions (3×3, 1 iteration)
   - Effect: removes noise, fills small holes

3. Connected Component Labeling
   - 8-connectivity flood fill
   - Identifies separate objects
   - Output: integer label per region

4. Geometry Filtering
   - Bounding box extraction
   - Statistics: size, area, position
   - Output: box coordinates


COMPARISON METRICS:
──────────────────
✓ Accuracy      : % of correctly classified pixels
✓ Precision     : TP / (TP + FP) - false positive rate
✓ Recall        : TP / (TP + FN) - false negative rate
✓ F1-Score      : Harmonic mean of precision & recall
✓ Confusion Matrix: TP, TN, FP, FN counts


IMAGE SPECIFICATIONS:
─────────────────────
- Resolution: 1920 × 1080 (Full HD)
- Total Pixels: 2,073,600
- Color Depth: 24-bit RGB
- Format: JPEG (input), Hex (processed)
- Memory per stage: ~50-100 MB

================================================================================
                          TROUBLESHOOTING
================================================================================

Issue 1: "Python 3.7+ required"
──────────────────────────────
Solution: Use Python 3.7 or later
  $ python3.7 /path/to/script.py
  $ python3.8 /path/to/script.py

Issue 2: "ModuleNotFoundError: No module named 'numpy'"
───────────────────────────────────────────────────────
Solution: Install missing packages
  $ pip install numpy scipy matplotlib Pillow
  
Or with specific Python version:
  $ python3.7 -m pip install numpy scipy matplotlib Pillow

Issue 3: "actual_morph_out.txt is empty"
─────────────────────────────────────────
Likely Cause: RTL simulation incomplete or morphology stage didn't execute
Solution:
  1. Check RTL simulation log for errors
  2. Verify actual_mask_out.txt has content
  3. Ensure testbench waited for morphology stage completion

Issue 4: "Accuracy is not 100%"
───────────────────────────────
Possible Causes:
  - Different rounding in RTL vs Python
  - One-off errors in boundary conditions
  - Different image scaling algorithm
  - Pipeline synchronization issues

Solution:
  1. Review detailed_report.txt for error regions
  2. Check error heatmaps in PNG visualizations
  3. Examine top error regions with coordinates
  4. Compare RTL logs for timing issues

Issue 5: "Memory error loading image"
─────────────────────────────────────
Solution: Available 3.6+ TB free, should not occur
  - Check system resources
  - Close other applications
  - Reduce image resolution if needed
